# Release notes

## 1.00 — First public release

- CT-to-atlas mapping through six reference marmosets with equal-weight averaging.
- Landmark-based or ANTs registration with rigid or similarity transforms.
- Interactive landmark placement, contrast controls, and alignment checking.
- Display of the atlas MR image, Nissl, myelin, and region labels in target CT
  space.
- Export of mapped images, landmarks, transforms, and numerical quality-check
  reports.
- A complete Windows package with the source code, BMA 2.0, the reference data of
  the six marmosets, and a standalone ANTs runtime.
