# Release notes

## 1.00 — First public release

- CT-to-atlas mapping through six reference marmosets, with equal-weight averaging.
- Landmark-based and ANTs registration with rigid or similarity transforms.
- Interactive landmark placement, contrast controls, and alignment checking.
- Atlas MRI, Nissl, myelin, and region-label viewing in target CT space.
- Saved images, landmarks, transforms, and numerical quality-check reports.
- A complete Windows package with source code, BMA 2.0, six reference datasets,
  and the standalone ANTs runtime.
