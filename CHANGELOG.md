# Release notes

## 1.00 — First public release

- CT-to-atlas mapping through six reference marmosets with equal-weight averaging.
- Landmark-based or ANTs registration with rigid or similarity transforms.
- Interactive landmark placement, contrast controls, and alignment checking.
- Viewing of the atlas MRI, Nissl, myelin, and region labels in target CT space.
- Saved images, landmarks, transforms, and numerical quality-check reports.
- A complete Windows package with the source code, BMA 2.0, the six reference
  datasets, and a standalone ANTs runtime.
