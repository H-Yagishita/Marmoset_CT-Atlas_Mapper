# Example data

No separate example dataset is included. To try the workflow, load a reference CT
and its Markups file from `data/reference_v2/` in the complete package. Because
that animal is also one of the references, this demonstrates the workflow only; it
is not an independent test of mapping accuracy.

For a new target, label the landmarks `LM01`–`LM08` for the skull-base set or
`LM01`–`LM13` for the total set. Their order in the file does not matter. At least
three non-collinear landmarks are required; five or more are recommended.
