# Example data

There is no separate example dataset. To try the app, load one of the reference
CTs and its Markups file from `data/reference_v2/` in the complete package. Since
that animal is also a reference, this only demonstrates the workflow and says
nothing about accuracy.

For your own CT, name the landmarks `LM01`–`LM08` (skull base) or `LM01`–`LM13`
(total). The order in the file does not matter.
